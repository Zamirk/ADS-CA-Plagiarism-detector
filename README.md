# Plagiarism Detector

University group project, 2017: a C++ console application exploring plagiarism detection through file hashing and text comparison. Preserved as historical student work.

## Features

- Read files from a selected directory.
- Calculate file hashes.
- Compare matching lines between files.
- Count selected C++ keywords and display comparison reports.

## Historical context

This project reflects my university work in C++, file handling, and text comparison. It is no longer actively maintained.

The original implementation uses Windows console APIs and fixed-size arrays for ten files. Its comparison methods and reporting logic are basic student implementations with known limitations.
